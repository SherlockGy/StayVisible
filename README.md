# 常亮 · StayVisible

一个简单的 macOS 菜单栏工具，让远程管理不被空闲锁屏打断。

开启期间临时暂停自动屏保、阻止空闲灭屏和空闲睡眠；停止、到时或退出后恢复。**保留手动锁屏和密码保护**，不模拟鼠标键盘。

## 使用

打开 `常亮.app`，选择保持时间，再点「开启」：

- 30 分钟、1 小时、2 小时，或直到手动停止。
- 关闭面板后，菜单栏太阳图标仍可控制。
- 每次启动默认关闭，不自动加入登录项。

开启时，附近的人可能看到或操作桌面。仅在可信环境中使用，离开时停止或手动锁屏。

## 构建

需要 Apple Silicon Mac、macOS 13+ 与 Apple Command Line Tools。无第三方依赖。

```sh
./build.sh
open dist/常亮.app
```

构建脚本会编译、运行不修改系统设置的逻辑自测、检查 Info.plist 并验证本地签名。产物是 **ad-hoc 签名，未经 Apple 公证**；推荐从源码本机构建，不建议绕过 Gatekeeper 警告。Intel Mac 尚未支持和测试。

## 原理与恢复

- 使用公共 IOKit 显示电源断言，不永久改写显示睡眠设置。
- 只将当前用户、当前主机的 `com.apple.screensaver / idleTime` 临时设为 `0`。原值先记录，再暂停屏保。
- 独立恢复子进程监听主进程管道。主进程异常退出或被强制结束，管道关闭后恢复原屏保计时。
- 恢复操作带互斥锁和会话标识，避免旧恢复进程处理新会话。若期间用户将屏保计时改为其他非零值，尊重新值。
- 不修改密码要求，不尝试解锁或绕过组织管理策略；无需管理员权限或辅助功能权限。

**恢复边界：**整机断电、同时终止主进程和恢复子进程，或恢复写入失败时，需重新打开应用完成恢复。应用没有安装常驻系统服务。组织管理策略下不保证生效。未验证所有 macOS 版本。

## 隐私

无联网、遥测、账号或后台更新。仅在 `~/Library/Application Support/StayVisible/` 存储恢复记录和进程锁，不读取密码或文档。恢复成功后删除恢复记录。

## 验证范围

已在 macOS 27.2.1 / Apple Silicon 验证：

- 编译、签名及逻辑自测。
- 面板开启、停止、取消、重启默认关闭。
- 开启时真实电源断言存在，屏保暂停；停止后原计时恢复、断言释放。
- 2 秒真实会话到期恢复、主进程强制结束后的子进程恢复。
- 单调时钟计时，系统日期跳变不影响时长。
- 恢复锁被占用时有界返回、保留恢复记录并提示重试；恢复子进程挂起不会卡住主界面。
- 密码要求和显示睡眠设置保持不变。

尚未完成长时间无人操作测试，未主动锁屏测试，不能承诺阻止一切锁定原因。
